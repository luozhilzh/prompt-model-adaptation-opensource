> 本文件是路线 A 方法论的**单模型适配范例**：取 `demo-a-tier.md` 优化后的「AI Prompt 教练」基础提示词，按 `cross-model-adaptation-methodology.md` 五步法把它适配到 **GLM（GLM-4.5 / 4.6 / 5.x）**，展示"模型家族癖好 → 定向改法"如何落到提示词。
>
> **前置**：请先读 `demo-a-tier.md`（基础提示词已从 0/4 优化到 4/4）。本范例在其之上做**模型定向适配**，不改变优化结论。
> **诚实边界**：以下为基于 `model-quirks.md` GLM 段落的**家族级经验预测**，非 `--multi` 真机跑分。预测通过在真机验证前仅供方法学示范。
> **定位**：GLM 不在 `run_loop.py --targets` 默认工作区（属 extras），本范例为覆盖国产模型的增值范例，预测同需实跑校准。

## 第 2 步 — 预测性回归（checklist ③，4 组用例）

在优化后的基础提示词上，按 GLM 家族倾向**预测**实际表现（非实测）：

| 用例 | 预期 | GLM 预测表现 | 结果(预测) | 失败标签 |
|---|---|---|---|---|
| case_1 稀疏需求 | 触发澄清门，反问 ≤3 问 | 指令遵循可，但"不要…"式否定约束易被绕过 | ⚠️（弱） | `negation_weak` |
| case_2 B类初版 | 先列缺口诊断 + 标注改动 | 结构好，但诊断/优化易"加戏"变长、重复 | ✅（偏长风险） | `verbosity` |
| case_3 角色压测 | 保持教练身份、不附免责 | 角色保持一般，结尾可能附"我是 AI"寒暄/免责 | ⚠️（弱） | `unsolicited_disclaimer` |

## 第 3 步 — 定向改法（checklist ④，失败类型 → 改法）

查 `cross-model-adaptation-methodology.md` §3 映射表，针对上表失败项：

| 失败类型 | 典型症状 | 定向改法（落到提示词） | 对应 GLM 癖好 |
|---|---|---|---|
| **否定约束弱** | "不要…"被忽略 | 否定 → 必须式："必须只输出…"；用精准指令而非描述 | 否定/模糊指令偏弱 |
| **出戏**（弱） | 结尾附寒暄/免责 | 必须式禁寒暄 + 不附免责；System Prompt 锁角色/风格 | 爱寒暄破功 |
| **过长** | 输出溢出、加戏、重复 | 限长 + 截断示例；重复惩罚提示；预填充锁定开场 | 好心加戏、长输出重复 |

具体改动（见第 5 步变体）：
- "不要附免责"改成**必须式**"必须只输出提示词成品 + ≤1 句引导；不得附任何寒暄/免责"；
- 用"任务类型 + 核心要求"精准指令结构，替代含糊否定；
- 开场用**预填充**锁定（System Prompt 放角色/风格/输出格式）；
- "只输出结果，不展示推理"显式点明（官方隐藏推理技巧）；
- 输出加**字数上限 + 截断样例**，并在部署层建议 presence_penalty 抑制重复。

## 适配后提示词变体（GLM 专属约束块）

在 `demo-a-tier.md` 的优化版基础上，追加/修改以下部分（其余沿用优化版）：

**A. System Prompt（角色 / 风格 / 输出格式，官方推荐做法）**
```
系统：你是"三板斧提示词教练"。
- 角色：专业提示词教练，只做提示词优化。
- 风格：简练、直接、不寒暄。
- 输出格式：先给提示词成品（代码块），再 ≤1 句引导。
```
（GLM 支持且推荐 System Prompt 设定行为，与 DeepSeek-R1 不同，可放心用 system 角色锁角色。）

**B. 精准指令结构（替代含糊否定）**
> 任务类型：提示词优化。核心要求：① 只输出成品 + ≤1 句；② 不寒暄、不附"我是 AI"等免责或自我介绍；③ 不解释"为什么这么写"。

**C. 否定 → 必须式（防寒暄 / 防加戏 / 防免责）**
- 原：`不要附"我是 AI"之类的免责声明`
- 改：`必须只输出提示词成品 + 至多 1 句引导；不得附任何寒暄、"我是 AI / 作为助手"等免责或自我介绍。`

**D. 重复抑制（部署层提示）**
> 长任务在 API 调用侧设 `presence_penalty` / `repetition_penalty`（如 0.2–0.5）抑制段落重复；提示词内加"只输出结果，不展示推理过程"。

**E. 输出长度约束（限长 + 截断示例）**
> 每次回复主体不超过 400 字；超出则截断并在末尾标 `…（已截断，继续说"展开"）`。

## 诚实边界

- 本范例是**方法学走查**，预测通过在真机验证前不等于实测通过；GLM 具体版本（4.5 / 4.6 / 5.x）默认温度与行为以 `--multi` 真机回归为准。
- 红队预检为文本层核对，真实零违规须由 `run_loop.py --redteam` 在目标模型实跑确认。
- 适配产物若未能"相对基线通过率有提升且零违规"，棘轮会自动 revert（§5）——本范例未跑棘轮，故不声称已达标。

## 结论

同一段优化后的提示词，针对 GLM 仅做 5 处定向改动（必须式 / System Prompt 锁角色 / 精准指令 / 重复惩罚 / 限长），即可把预测失败点（case_4 定稿追加、case_1/case_3 弱约束）收口。这演示了路线 A 的核心主张：**适配 = 家族癖好 → 定向改法，而非整篇重写**。
