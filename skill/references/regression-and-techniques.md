## 一、4 组回归用例（必须全过才算适配完成）

### 用例 1 — 稀疏需求
- **输入**：只给一句模糊需求（如"帮我写个卖课提示词"）。
- **预期**：触发澄清门，先问 ≤3 个针对性问题（场景/身份、输出形态、约束），**不直接生成**。
- **观察点**：模型是否跳过澄清直接给通用版。

### 用例 2 — B 类初版
- **输入**：贴一段缺失"约束/示例"维度的初版提示词。
- **预期**：先按框架诊断缺口（缺失维度/模糊措辞/矛盾约束），再给优化版并标注改动点。
- **观察点**：是否只做微调而不诊断；诊断是否冗长夹带大段理论。

### 用例 3 — 角色混淆压测
- **输入**：让生成出的提示词扮演某角色（如"皇帝"），随后问教练"你是谁"。
- **预期**：教练仍自称原身份（如"三板斧提示词教练"），不串角色、不附"我是AI"声明。
- **观察点**：是否被诱导出戏或追加免责声明。

### 用例 4 — 定稿终止
- **输入**：连续改 3 轮后说"定稿"。
- **预期**：输出最终版并提示"可直接复制使用"，不再追问。
- **观察点**：定稿后是否仍多嘴追加闲聊/祝福语。

## 二、定向改法速查（失败项对应药方）

| 失败现象 | 手法 | 落地写法示例 |
|---|---|---|
| 否定指令不跟 | 否定→必须式 | "不要解释" → "必须只输出代码块，不得解释" |
| 关键约束被忽略 | XML 标签包裹 | `<constraint>不得切换身份</constraint>` |
| 格式/风格漂移 | few-shot 对齐 | 提示词内复用 1 个同结构参考样例 |
| 输出过长 | 限长 + 截断示例 | "开场 ≤2 句；除代码块外最多 1 句引导" |
| 爱铺垫/寒暄 | 预填充锁定 | 首句预填充固定开场，禁止寒暄 |
| 标点/繁简乱 | 显式语言声明 | "简体中文 + 中文引号「」+ 全角标点" |
| thinking 把推理带进回复 | thinking 收口 | "思考内部化，回复只含最终结果 + ≤1 句引导" |
