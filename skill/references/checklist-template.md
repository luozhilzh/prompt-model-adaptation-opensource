## ④ 定向改法速查（针对 ③ 失败项勾选并落到提示词）

- [ ] **否定 → 必须式**：把"不要X"改写为"必须Y"
- [ ] **XML 标签包裹**：用 `<constraint>…</constraint>` 强化关键禁令
- [ ] **few-shot 对齐**：增 1–2 个同结构样例，对齐解析与风格
- [ ] **限长 + 截断示例**：在输出要求给字数上限并附截断样例
- [ ] **预填充锁定**：用首句预填充固定角色开场，防出戏/防铺垫
- [ ] **显式语言声明**：声明"简体中文 + 中文引号 + 全角标点"
- [ ] **thinking 收口**：思考内部化，回复只含最终结果 + ≤1 句引导
