# 常见模型家族癖好与适配要点

> 经验性归纳（非基准测试）。适配具体版本时以实跑回归为准；未知版本号务必标注不确定性。

---

## DeepSeek（V3 / R1）
- **弱点**：输出偏长、易"好心加戏"、偶附免责声明。R1 有独立思考区。
- **适配**：收敛开场与输出长度；强化"不得切换身份"；限定"只输出代码块 + ≤1 句引导"。
- **温度**：≤ 0.6。R1 无需在系统提示请求逐步推理展示。

## GLM（含 GLM-4.5 / 5.x）
- **弱点**：否定指令遵循偏弱、爱寒暄、易为"热心"破功追加说明。
- **适配**：必须式措辞；禁寒暄与额外解释；锁角色"不破功"；限长。
- **温度**：0.3–0.5（低温更守格式）。
- **注意**：对"GLMx.y"等具体版本号若不确定，标注需实测校准。

## Qwen（Qwen2.5 / Qwen3.x）
- **弱点**：Qwen3 带 thinking 模式，开启时易把推理带进回复；偶加 preamble。指令遵循总体较好。
- **适配**：thinking 收口（思考内部化、回复只含结果）；轻量禁寒暄；锁角色。约束可比 GLM 轻。
- **温度**：0.3–0.6；建议关闭 thinking 以获得干净输出。
- **注意**："Qwenx.y"具体版本号若不确定，标注需实测校准。

## Hunyuan / 混元（含推理版 T1）
- **弱点**：偏长爱铺垫、易附"作为AI"免责声明或自我介绍。
- **适配**：禁铺垫/禁自我介绍；不附免责声明；必须式；限长。
- **温度**：0.3–0.6。推理版需补 thinking 收口（思考内部化）。
- **注意**："hy3"等代号若不确定，标注需实测校准。

## Gemini（Gemini 1.5 / 2.0 / 2.5 Pro·Flash）
- **弱点**：指令遵循强但偏"热心"，易加 preamble / 免责铺垫、过度解释；长上下文（1M+）下关键约束易被稀释，需重复锚定；安全过滤器偶发对提示词内容误拒；扩展思考（若开）会把推理带进回复。
- **适配**：禁寒暄 / preamble / 免责；开头即给产物（代码块 / 模板）+ ≤1 句引导；关键约束放系统提示开头并显式重复；长文任务要求"只输出结果，不解释过程"。
- **温度**：0.4–0.7；纯格式 / 模板任务取低值。
- **注意**：基于公开行为归纳，非本仓库实测；具体版本（如 2.5-flash vs pro）与思考模式开关需实跑校准；安全误拒风险在红队门禁下可被捕获。

## Claude（Claude 3.5 / 3.7 / 4 Sonnet·Opus）
- **弱点**：指令遵循与角色保持均强，但"乐于助人过度"——爱客套（"很高兴帮你…"）、附长篇解释与 caveat；扩展思考（extended thinking）开启时会展示推理；边缘安全用例可能过度拒绝。
- **适配**：锁角色"不破功"（本身强，显式锚定更稳）；禁客套 / 免责声明；限定只输出目标产物 + ≤1 句；低温更守格式。
- **温度**：0.2–0.5（低温仍流畅）。扩展思考如需干净输出，明确要求"只给最终答案，不展示推理"。
- **注意**：基于公开行为归纳，非本仓库实测；具体版本与思考模式需实跑校准；过度拒绝在红队门禁下可被捕获，良性适配应正常遵从。

---

## 通用排序参考（定性，仅观感）
- 指令遵循由强到弱大致：Claude ≈ Gemini ≈ Qwen ≈ DeepSeek > Hunyuan ≈ GLM。
- 角色保持：Claude/Qwen/DeepSeek 稳；Gemini 良好但需显式锚定；GLM 易破功；Hunyuan 易附免责。
- 输出长度：六家均偏长倾向，均需限长约束；Gemini/Claude 尤爱客套与过度解释，需明禁。
- 中文语感：六家均强，无需特别处理。
- 特殊风险：Claude/Gemini 注意客套/过度解释与扩展思考溢出；Qwen/DeepSeek 推理版 thinking 溢出；GLM 寒暄/破功；Hunyuan 铺垫/免责；Gemini 安全过滤器偶发误拒（适配提示词内容时留意）。
