# DeepSeek 专属癖好与定向改法（手写实观察）

> **性质**：以下为作者真实部署 DeepSeek（V3 / R1）后观察到的模型癖好，及在 `adapted_prompt.md` 中实际落地的定向改法。
> 属**手写实观察**——来自真实使用经验与「前/后」提示词 diff，**非** `--multi` 真机实证校准（实证见本目录 `README.md` 升级路径）。
> 定向改法手法名取自 `skill/references/regression-and-techniques.md` §二「定向改法速查」。

---

## 观察清单

| # | 癖好 / 弱点（DeepSeek 语境） | 在教练提示词中的触发症状 | 定向改法（手法 + 落点） | 对应失败类型 |
|---|---|---|---|---|
| Q1 | 倾向**冗长 / 发散**，尤其无温度约束时 | 开场寒暄、步骤间大段解释三板斧理论、定稿后追加祝福语 | **限长 + 截断示例**：步骤 1「不要展开解释…不要多写」；步骤 3「除代码块外最多 1 句引导，不得额外解释」；部署须知**温度 ≤ 0.6** | 过长 |
| Q2 | R1 类推理模型**忽略 system 角色约束**（thinking 在独立区） | 经 system 传入的硬性约束被跳过 | **否定→必须式**兜底 + 部署层约束经 **user 提示**传入（见 `running-real-adaptation.md` §10 风险 R1）；prompt 内仍用硬约束 | 指令模糊（流程门未生效） |
| Q3 | 易被诱导**出戏 / 附"我是 AI"免责声明**（角色混淆压测易翻车） | 用户让其扮演生成提示词里的角色后，身份漂移、自报 AI | **否定→必须式**：「始终保持三板斧提示词教练身份，不得出戏、不得附'我是AI'之类免责声明」 | 出戏 |
| Q4 | **定稿后仍多嘴**（终止门失效） | 用户说"定稿"后仍追问"还需要调整吗"或补闲聊 | **否定→必须式 / 预填充锁定**：步骤 4「然后停止，不再追加闲聊」 | 否定失效 |
| Q5 | **格式 / 板块漂移**（自行增删标题） | 输出私自增减四级标题或调换顺序 | **few-shot 对齐 + 显式格式锁定**：输出格式「顺序与板块数量不可调换，不得自行增删」 | 格式崩 |

## 改法如何对应回归用例

- **Q1 + Q4** → 直接服务 **用例 1（稀疏需求澄清门）** 与 **用例 4（定稿终止）** 的"不啰嗦 / 不追问"要求。
- **Q3** → 直接服务 **用例 3（角色混淆压测）**：硬约束让模型在角色压测下不出戏、不附免责声明。
- **Q5** → 服务 **用例 2（B 类初版）** 的"输出格式可被直接套用"与 `adds_missing_sections` 维度。
- **Q2** → 属部署层防护，确保 R1 下上述约束真正生效（否则会退化为"指令模糊"类失败）。
